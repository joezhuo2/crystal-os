# Code of Conduct

## Our pledge

We want everyone to be able to take part in this project without harassment, whatever their age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our standards

Behaviour that helps:

- being kind and patient with other people,
- respecting opinions and experiences that differ from your own,
- giving feedback about the work, not the person, and accepting it the same way,
- owning your mistakes and learning from them.

Behaviour that is not accepted:

- sexualised language or images, and unwelcome sexual attention,
- insults, trolling, and personal or political attacks,
- harassment, in public or in private,
- publishing someone's private information, such as an address or an email, without their permission,
- any other conduct that would be inappropriate in a professional setting.

## Scope

This Code of Conduct applies in every project space: issues, pull requests, discussions and code review. It also applies when someone represents the project in public.

## Enforcement

Report unacceptable behaviour to the maintainer through the contact options on their [GitHub profile](https://github.com/joezhuo2). Reports are reviewed promptly and kept private.

The maintainer may remove, edit or reject comments, commits, code, issues and other contributions that break this Code of Conduct. The response depends on how serious the behaviour is:

1. **Correction.** A private note that explains what was wrong.
2. **Warning.** A warning with consequences if the behaviour continues.
3. **Temporary ban.** No interaction with the project for a set time.
4. **Permanent ban.** No further interaction with the project.
